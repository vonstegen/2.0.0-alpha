# Define: Living Archive Human-First Copy

## User Outcome

A user opening Living Archive understands the memory model before seeing implementation terms:

> Human Knowledge is preserved; AI Memory is the maintained wiki.

## Scope

- Living Archive Start tab leading explanation.
- Memory settings section explanation.
- First-run recommended defaults explanation.
- Help tab explanation.
- Bundled Living Archive manifest description used by onboarding.
- Regression tests for these surfaces.

## Acceptance Criteria

- The exact sentence appears in the Living Archive Start tab.
- The exact sentence appears in the Memory settings section.
- The exact sentence appears in first-run onboarding when Living Archive is a recommended memory add-on.
- The exact sentence appears in the Help tab.
- Obsidian-compatible vaults are described as optional.
- Implementation terms are not the first explanation of the feature.
- Focused UI test passes.
- Build and full test suite pass or any blocker is recorded.
