## Authority and status rules

| Layer | Authority | Practical rule |
| --- | --- | --- |
| Shipped Alpha | Pinned `dev` runtime boundary, current status, module ownership, issues and Project 2 | Extension plus authenticated Node bridge. Feature-branch terminal plans do not redefine release scope. |
| Accepted decision on a candidate line | ADR body and metadata at the applicable candidate SHA, together with its acceptance evidence | ADR “Accepted” is decision status; it does not mean merged, fully implemented, independently tested or live-proven. |
| Implementation | Actual code and tests at the named SHA | Scope every implementation claim to its branch/commit. |
| Live proof | Exact candidate, environment, provider/model, execution and cleanup evidence | A standalone proof does not prove a later composed session or product UI. |
| Architecture synthesis | Reviewed Markdown with evidence links | Recommended readable entry point; cannot override a current scoped ADR or code evidence. |
| Presentation | LaTeX derived from the same Markdown revision | No separate authority and no stronger claim. |
| Historical / R&D | Frozen original files and explicit successors | Preserve provenance; do not interpret target diagrams as runtime evidence. |

Required implementation vocabulary is independent of document review state:

| Label | Meaning |
| --- | --- |
| IMPLEMENTED | Code for the stated behavior exists at a named commit. |
| TESTED | Named tests have executed against that commit; identify runner, result and limits. Distinguish reported from independently verified results. |
| PROVEN LIVE | The exact stated path executed using real components; name environment and proof limits. |
| PLANNED | A documented target or future phase; no completion claim. |
| NOT YET IMPLEMENTED | The inspected line does not supply the stated runtime connection or behavior. |

“Proposed”, “Accepted”, “Historical” and “Superseded” describe document/decision governance, not test or implementation results. No existing ADR metadata is changed by this index.
