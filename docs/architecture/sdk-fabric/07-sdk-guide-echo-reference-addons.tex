\section{SDK Echo 2.0}
Echo is the canonical Hello World and proves the minimum add-on lifecycle without provider credentials, memory, harness runtime, broad filesystem access or Core-specific code.
\section{SDK Guide 2.0}
Guide is the human-facing frontend to the same Dynamic SDK category registry consumed by AI developers. It should teach categories, required architecture, optional facilities, references, manifests and validation.
\section{Reference Suite}
SDK Guide provides onboarding, SDK Echo provides the minimum example, Pi provides the advanced harness example, Reference Memory demonstrates data-source replacement, and GitHub demonstrates external connector integration.
