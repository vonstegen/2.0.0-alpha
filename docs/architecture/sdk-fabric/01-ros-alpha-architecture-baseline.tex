\section{Canonical dimensions}
\begin{itemize}\item classification: what\item runtimeType: how\item surfaces: where\item requestedCapabilities: authority requested\item systemSlots: ROS role\item credential/provider requirements: authentication/inference resources\end{itemize}
Classification never grants authority.
\section{Current gaps}
No universal provides/requires fabric exists yet; not every ROS subsystem is behind a uniform module contract; durable encrypted credential storage and provider-native AI connectors remain future work.
