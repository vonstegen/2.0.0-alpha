\section{Definition of Done}
This revision must prove both a real Pi.dev harness add-on and a reusable External SDK that a fresh developer or AI harness can use without modifying ResonantOS Core.
\section{Pi Reference}
ROS provisions provider/model, project/files, memory, skills, selected tools and grants. The user launches the real Pi native TUI either through an embedded PTY or an external terminal. No manual bridge, RPC process, credential export, directory setup or Pi startup is required.
\section{Community SDK}
Canonical categories are harness, tool, connector, communication, data-source, UI and service. Harness kits describe classification, runtime, interface, Provider Connection, resource projection, capabilities, slots, surfaces, lifecycle, security, validation and testing.
\section{Final Proof}
A fresh AI developer receives only the Community SDK, public docs and reference add-ons and must build/install a new add-on without Core changes.
