\section{North star}
ResonantOS is the durable user-owned context/capability layer beneath replaceable AI applications and harnesses. Provider-native applications retain their UI while receiving governed ROS context and tools; ROS-hosted harnesses receive safe ROS surfaces.
\section{Contract direction}
Consumers and providers connect through SDK contracts. A future provides/requires graph should decouple Pi from a particular memory implementation and GitHub from a particular credential implementation.
\section{Sovereignty}
Prefer capability and credential-use mediation over raw secrets. Clients receive scoped context projections. Durable memory mutation remains governed by a memory authority.
\section{Protocols}
MCP is an important transport, not the canonical ROS architecture. ROS contracts should adapt to MCP, ACP, CLI, HTTP, and future transports.
