4. Host consent
idle

      
Try /addons/workspace/grant with consent:false — the registry throws permission-denied. This step proves setGrants refuses to self-grant.

      
      

    


    

      
5. Grant
idle

      
POST /addons/workspace/grant with consent:true flipped grantedCapabilities[network].granted to true. The bootstrap envelope now carries the host-minted bearer.
